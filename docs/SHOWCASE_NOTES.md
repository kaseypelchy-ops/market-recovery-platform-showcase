## Social preview

`assets/social-preview.png` is sized for use as a GitHub repository social-preview image.

On GitHub:

1. Open the repository.
2. Go to **Settings → General**.
3. Find **Social preview**.
4. Upload `assets/social-preview.png`.

## GitHub Pages

This repository includes `.github/workflows/pages.yml`.

After pushing to a public repository:

1. Open **Settings → Pages**.
2. Set the source to **GitHub Actions** if required.
3. Push to `main`.
4. The workflow publishes the repository root as a static site.
