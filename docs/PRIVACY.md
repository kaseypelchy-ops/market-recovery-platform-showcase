# Public Showcase Privacy Policy

This repository is intended for public portfolio use. It demonstrates system architecture and engineering decisions without publishing production information.

## Never include

- customer names
- customer addresses
- customer account IDs
- customer emails or phone numbers
- employee credentials or internal-user records
- production Supabase keys
- production database connection strings
- live project URLs that expose internal administration
- raw sales/disconnect exports
- real market ranking/distress lists
- internal financial performance
- confidential promotion economics
- exact private scoring weights/cutoffs if they are not already approved for public release
- operational notes that identify customers, vendors, or employees

## Synthetic-data rule

Every interactive metric in this showcase is fictional.

Synthetic market names used by the demo include:

- Pine Valley, PA
- Riverton, TX
- Lake County, NC
- Summit, NV
- Cedar Ridge, KY

They are used only to demonstrate different analytical/lifecycle states.

## Architecture disclosure

The public showcase may describe high-level architecture such as:

- normalized events
- canonical market identity
- trend analytics
- recovery scoring
- recommendation eligibility
- recovery projects
- historical snapshots
- PostgreSQL optimization
- shared TypeScript data/domain modules

This communicates engineering depth without disclosing production records.

## Before publishing future screenshots

Check for:

1. browser URL / project identifier
2. real market names paired with performance
3. customer or employee names
4. email addresses
5. IDs or UUIDs
6. production error logs with database identifiers
7. internal pricing or margin information
8. hidden sidebars, tooltips, or table rows containing sensitive data

When in doubt, recreate the screen with synthetic data instead of publishing a production screenshot.
